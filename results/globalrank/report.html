  • 6 variants were run in development and are all logged; with that many, luck alone would give the best one a Sharpe of about 0.16.

1. Question and setup

Each month the bot ranks country stock indexes (14 European, 8 others, and emerging markets) by their expected return over the next 3 months, holds the top third in equal weight, and keeps a holding until it drops out of the top half. The target is to beat buy-and-hold of the developed world (a free proxy for MSCI World) with a worst fall no larger than the benchmark's. Rules were written down before any result: docs/globalrank_preregistration.md.

No truly unseen history is left: 2015-2025 was the previous project's test and 2022-2025 is recent memory. The 2022-2025 test below is a check, not proof. Every variant run is logged and counted in the deflated Sharpe ratio.

Data (all free)

Country indexes: Kenneth French international country returns (value-weighted, dividends included, in USD), the US from CRSP, emerging markets and the developed-world benchmark from French's regional files; converted to EUR with the project's EUR/USD series; ETF running costs (0.30%/yr, world 0.20%/yr) deducted. Individual European stocks are not used: free sources list only today's survivors, which flatters a stock-picking model.

Inputs and models

Inputs, price-only and ranked across indexes each month: returns over 1, 3, 6 and 12-1 months, distance from the 12-month high, 12-month volatility, drawdown, 36-month correlation with the world, 12-month trend slope. Models: M0 plain 12-1 momentum rank (no AI); M1 ridge regression; M2 gradient-boosted trees (LightGBM-style); M3 a small neural network, run only if M2 beats M0. Training uses only labels whose 3-month window ended at least one month before the decision (purged walk-forward, expanding window from 1978).

Costs and tax: 0.10% per trade; accumulating UCITS ETFs, so gains are taxed at 26% when sold and ETF losses cannot offset ETF gains (Italian redditi di capitale vs redditi diversi); everything sold and taxed at the end.

4. Answers to the two questions

Is European data easier, and is there enough free data? For indexes, yes: free, survivorship-safe monthly total returns exist for 14 European countries from 1975-1991, enough for this kind of test. For individual European stocks, no: free sources lack delisted companies, point-in-time index membership and clean fundamentals, so a stock-level model would be flattered by survivors. Paid data (several hundred to thousands of euros a year) would be needed.

Can it run fully automated? Yes: one command downloads the data, rebuilds every input point in time, trains the models walk-forward, applies costs and tax, runs the test and writes this report. In PyCharm, run the module src.globalrank.run_all with the project's .venv interpreter; in Claude Code, ask it to run .venv\Scripts\python -m src.globalrank.run_all.

5. Limits

  • Indexes are French's value-weighted country returns, close to but not the same as MSCI indexes; real UCITS ETFs track MSCI with their own costs and small gaps.
  • EUR/USD before 1999 uses monthly averages (as in project 1).
  • Some small markets (Austria, Ireland, New Zealand, Malaysia) have few or no UCITS ETFs an Italian investor can buy; check availability on Borsa Italiana.
  • The tax model is a simplification of the Italian rules and should be checked with a tax adviser.
  • The 2022-2025 test is short (48 months): a Sharpe ratio has a standard error of about 0.5 over 4 years.
